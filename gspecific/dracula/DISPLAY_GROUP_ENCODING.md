# Dracula MES 화면 그룹 인코딩

드라큘라의 `annotate_display_groups.py`가 만든 `display_groups`를 인코더가
사용합니다. 번역된 화자의 길이를 계산하여 화자 뒤에 ASCII 공백 한 칸을
넣고, 같은 화면 그룹의 이어지는 줄은 `[화자] `가 차지한 칸 수만큼 들여씁니다.

표시 폭은 40칸입니다. 긴 번역문이 40칸에 도달해 다음 줄로 넘어가도 같은
화자 시작 열을 유지하며, 새 줄바꿈 제어문자를 삽입하지 않고 텍스트 영역의
공백으로 정렬합니다.

정렬과 줄맞춤은 MES 인코딩 중 메모리에서만 적용됩니다. 인코딩 종료 후
`*_lang.json`의 `translation` 값은 입력 당시의 값으로 복원되므로, 번역
문장에 정렬용 공백이 추가되지 않습니다.
