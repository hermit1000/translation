# DOB1 / Marine Philt 명령 경계와 번역 보정 비교

2026-09-06, Conda base에서 workspace2(DOB1), workspace4(Marine)의 원본과
현재 info/lang을 읽기 전용으로 조사했다. Juice ADV에서 참고한 부분은
명령 인자와 표시 문자열을 구분하는 방식이다. 실행 파일 의미 분석이나
게임 실행 검증은 하지 않았으며, 완전한 분기/반복 문법을 구현한 것은 아니다.

## 반영한 개선

### DOB1

MES 82개에서 기존 raw BA 검색과 lexer의 CALL_BUILTIN + argument를 비교했다.
18,420개 호출 모두 시작 위치, 마지막 바이트 위치, 인자 값이 일치했다.
raw 검색만으로 찾은 추가 호출은 없었다.

인코더의 raw BA 보완 검색을 제거했다. 기존 토큰 호출 처리는 유지한다.
이제 따옴표 인자 내부의 우연한 BA 23 등을 화자 매크로로 치환하지 않는다.
회귀 테스트에서 실제 호출은 치환하고, 같은 바이트가 든 인자는 보존하는
것을 인코더 CLI 경로까지 확인했다.

### Marine Philt

MES 134개와 현재 번역 입력 8,700건을 검토했다. 원본 해시, info/lang 참조,
원문과 raw_hex를 검사하고 DOB2 화자 보정 적용 전후를 비교했다.

| 결과 | 건수 |
| --- | --- |
| 두 방식 모두 성공하고 출력 바이트 해시·크기가 일치 | 8,262 |
| 두 방식 모두 같은 폰트 인코딩 오류 | 438 |
| 출력 또는 오류가 달라진 레코드 | 0 |
| DOB2의 괄호 범위 확장 조건에 해당하는 번역 레코드 | 0 |

Marine CLI는 `speaker_repairs=False`로 호출하여 DOB2의 원문 추정 보정과
괄호 범위 확장을 모두 끈다. 줄 너비와 기존 inline ASCII prefix 처리는
유지한다. DOB2 CLI의 기존 동작은 바뀌지 않는다.

438건은 이번 변경으로 발생한 오류가 아니다. 기본 font_table-kor-jin.json을
기준으로 35개 파일에서 `·` 누락 424건, 작은따옴표 누락 14건이 발생했다.
이들은 성공 비교 건수에 포함하지 않았다. 번역문과 폰트표는 수정하지 않았다.

## ASCII와 selector 관찰

`21 <printable ASCII> 00`의 선택적 구조 해석을 기존 기본 결과와 비교했다.
모든 비교에서 바이트 전체 복원 및 오프셋·길이 검증을 수행했다.

| 게임 | ASCII 출력 구간 | 텍스트 레코드 차이 |
| --- | --- | --- |
| DOB1 | 1,224 | 3,312 |
| Marine | 2,648 | 30 |

차이는 변경 전후 offset 집합에서 세므로 레코드 분할/병합도 여러 건으로
계산된다. 3,312건이 서로 독립적인 문장 오류라는 뜻은 아니다.

DOB1의 예는 000001.MES 01EEF의 `Select Save Number.`이다. 기존 기본
lexer는 ASCII 영문을 여러 압축 문자 레코드로 분리한다. Marine의 30건은
모두 STAFF_CR.MES에 있으며, 000D0의 `(RUSH-TEAM)` 닫는 괄호 누락과
콜론/공백 영역의 오해석 등이 포함된다.

기존 메타데이터와 번역 범위에 영향을 주므로 두 게임의 기본 추출 방식은
유지하고, 보고서의 `ascii.text_changes`에 변경 전후 원문·범위·바이트를 남긴다.

Marine selector 보정은 000059.MES에서 8건을 확인했다. 위치는
00346/00372/003B4/003DF/0061E/0064A/0068C/006B7이며,
10/12/14 00 xx 뒤 화자 괄호라는 기존 조건에 해당한다. 이 표본만으로
그 명령의 모든 인자 문법을 확정할 수 없으므로 기존 조건을 확대하지 않았다.
분기·반복 경계의 의미 역시 추가 런타임 분석이 필요하다.

## 재현

저장소 루트에서 실행한다. 보고서 외에는 쓰지 않는다.

```powershell
python -m gspecific.adv_common.audit_games C:\work_han\workspace2 C:\work_han\workspace4 .tmp\dob1_marine_audit.json
```

보고서에는 파일별 macro 차이, ASCII 변경 전후, selector 원본 바이트,
Marine 인코딩 차이와 오류 위치가 들어 있다. font-table 옵션으로 실제
사용하는 폰트표를 지정할 수 있다. 기존 게임 바이너리와 번역 JSON은
이번 작업에서 생성하거나 덮어쓰지 않았다.
