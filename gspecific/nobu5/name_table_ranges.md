# NOBU5 MAIN.EXE 이름 테이블 범위

기준 파일: `gspecific/nobu5/extract_nb5_name_scripts.py`

이번 `set_code_from_db_nobu5.py`에서는 성명 쌍만 처리한다. 아래 단독 이름 테이블은 추후 필요할 때 별도 규칙을 추가한다.

## 단독 성/지역명 테이블

- 테이블 시작: `0x5DED6`
- 레코드 크기: `0x26`
- 레코드 수: `173`
- 테이블 끝: `0x5F883`
- 이름 필드 오프셋: 레코드 기준 `+0x06`
- 이름 필드 크기: `8` bytes
- 첫 이름 필드: `0x5DEDC-0x5DEE3`
- 마지막 이름 필드: `0x5F864-0x5F86B`

이 테이블은 성 또는 지역명처럼 단독으로 쓰이는 이름 필드다. 성명 쌍이 아니므로 `NameDB.full_name_db`로 바로 조회할 수 없다.

## 여성 이름 테이블

- 테이블 시작: `0x5F884`
- 레코드 크기: `0x0E`
- 레코드 수: `10`
- 테이블 끝: `0x5F90F`
- 이름 필드 오프셋: 레코드 기준 `+0x04`
- 이름 필드 크기: `8` bytes
- 첫 이름 필드: `0x5F888-0x5F88F`
- 마지막 이름 필드: `0x5F906-0x5F90D`

이 테이블도 단독 이름 필드다. 추후 처리 시에는 `given_name_db` 또는 별도 여성 이름 규칙을 기준으로 변환하는 편이 안전하다.
